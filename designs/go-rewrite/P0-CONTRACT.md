# Go rewrite — contract layer (P0)

This directory holds the checks that gate the Go rewrite (P1 onward). They exist
to make incompatibility a **test failure** rather than a bug report after
release.

Nothing here serves a feature. Everything here constrains one.

## Why this layer runs first

The risk in a rewrite is not "the Go code will not compile". It is that the Go
build *looks* correct and disagrees with the Python one in a way nobody notices
until a user acts on it:

| Drift | What breaks | Invisible because |
|---|---|---|
| A route is missing | A UI action 404s | Only that one path is dead |
| A JSON property is missing | A panel renders blank | No error, just no data |
| An enum member is gone | An event is dropped | The reducer's `default:` swallows it |
| A `required` flag relaxed | A field arrives `null` | Types still line up |
| UUID decoded as a string | Ids look like garbage | Only visible on old rows |
| Compression frame misread | History is unreadable | Only on databases written earlier |

Every one of these compiles. Every one of them is caught below.

## Layout

```
go/
├── cmd/openapi-diff/          A1–A3  HTTP surface comparison
├── internal/event/            A4     the 56 SSE event types
├── internal/db/               A5–A6  on-disk encodings
└── testdata/
    ├── reference.db           Python-written database, the A5/A6 oracle
    ├── enum_codes.json        the SMALLINT code tables
    └── reference_ids.json     the seeded ids, so tests need not hardcode hashes
```

## Running

```bash
# everything (seconds, offline)
bash designs/go-rewrite/run-contract.sh

# one check
bash designs/go-rewrite/run-contract.sh A5
```

Evidence lands in `designs/go-rewrite/evidence/contract/<ID>/`
(`output.log` + `manifest.txt`).

## The six checks

### A1 — path set (117)

`openapi.json` is the single source of truth. The Go build must serve exactly
the same paths. An addition warns; a removal fails.

### A2 — operations (154)

Same paths, same methods. Also compares each operation's documented responses,
request-body required-ness, and parameter list, because a handler that exists
but ignores a query parameter is broken in a way a route listing does not show.

### A3 — schemas (194)

Three things a client binds to:

- **properties** — a dropped one renders blank
- **required** — a relaxed one sends `null` where a value is expected
- **enum members** — a dropped one is a value the client cannot render

Pydantic puts enums on properties, so both levels are compared.

#### Why the diff tool has its own negative tests

`cmd/openapi-diff/main_test.go` mutates a copy of the real spec and asserts the
tool fails. A comparator that always reports "no differences" would pass a
same-vs-same smoke test and provide zero protection — the exact failure this
layer exists to prevent. There are nine cases: missing path, missing operation,
missing schema, missing property, relaxed `required`, shrunken enum, dropped
union member, and one that asserts additions *warn* rather than fail.

### A4 — the 56 SSE event types

`ServerStreamEvent` is a discriminated union; the web client switches on the
discriminator. `internal/event/streamevents.gen.go` is generated from
`openapi.json` and compared against it **at test time**, so a schema change
that nobody regenerated fails `go test`.

Note: 56, verified against the document. `HarnessStreamEvent` is an internal
runner↔harness event and does not appear in `openapi.json`.

### A5 — reading a Python-written database

`testdata/reference.db` is generated by `make-reference-db.py` through the
**production** encoders, so it is a real database rather than a guess at the
format. It deliberately covers:

- `Uuid16` as 16 raw bytes, nullable and non-nullable
- every `ITEM_TYPE` and `ITEM_STATUS` code
- `CompressedText` as a zstd frame, a raw frame, legacy `TEXT`, and legacy
  `BLOB`
- a parent/child conversation pair

Regenerate when the Python schema changes:

```bash
python designs/go-rewrite/make-reference-db.py
python designs/go-rewrite/gen-enum-codes.py
```

`run-contract.sh` warns when the fixture is older than its generator.

### A6 — the three encodings

| Encoding | Contract |
|---|---|
| `Uuid16` | 32 bare hex chars ↔ 16 bytes; dashed and `uuid:`-prefixed forms accepted on input |
| enum codes | append-only `SMALLINT`; the Go table must equal the Python dump exactly |
| `CompressedText` | `[0x00][codec][payload]`; `0x00` raw, `0x01` zstd; unframed legacy text passes through |

The compression test covers all four on-disk states. A fifth check
(`verify-go-interop.py`) runs the other direction: it feeds a frame written by
Go through the **production Python decoder**, which is what a rollback would
do.

```bash
python designs/go-rewrite/verify-go-interop.py
# OK   pair 0 (raw): 45 frame bytes -> 43 chars
# OK   pair 1 (zstd): 74 frame bytes -> 363 chars
# All frames decode in Python: the Go encoder is compatible
```

## Generated files

| File | Generator | Source of truth |
|---|---|---|
| `internal/db/enumcodes.gen.go` | `gen-enum-codes.py` | `omnigent/db/enum_codecs.py` (via the dump) |
| `internal/event/streamevents.gen.go` | `gen-stream-events.py` | `omnigent/server/schemas.py` (via `openapi.json`) |

Both are verified against their source at test time, so forgetting to
regenerate surfaces as a test failure with the regeneration command in the
message.

## What this layer does *not* do

- No HTTP server, no database writes, no browser, no runner.
- It does not prove the Go build *behaves* like the Python one — that is what
  the Playwright suites (B1–E5) do, against a real Go server.
- It does not cover `web/`: the frontend is reused unchanged, and A1–A4 are
  what keep it working.
